# Webmaster Portfolio

Responsive starter portfolio built with **HTML5, CSS3, and vanilla JavaScript**.

## Sections
Home · About · Skills · Projects · Contact

## Features
- Responsive desktop, tablet and mobile layout
- Accessible mobile navigation and skip link
- Light/dark theme toggle
- Project filter (All / Web / SEO)
- Basic meta description, semantic HTML, and JSON-LD
- Dependency-free static files

## Local development
Open `index.html` in a browser, or use the Live Server extension in VS Code.

## Deployment
After approving and merging the Pull Request, open GitHub **Settings → Pages → Deploy from a branch** and choose **main / (root)**. The anticipated URL is https://tom-jenjira.github.io/webmaster-portfolio/ (available only once Pages is published).

## Before publishing professionally
- Replace the generic introduction and JSON-LD placeholder with verified personal information.
- Replace the illustrative project cards with actual case studies, images and results.
- Add your preferred professional contact details.
- Confirm the deployment URL before adding a canonical URL.
- Test responsive views at 360px, 768px and desktop; check console and Lighthouse.

## Manual QA checklist
- [ ] Menu opens/closes with correct expanded state; Escape closes menu.
- [ ] Section anchors navigate properly.
- [ ] Light/dark theme toggles.
- [ ] All, Web, SEO filters show the correct cards.
- [ ] Content fits mobile without horizontal overflow.
- [ ] Keyboard focus is visible on interactive elements.

**Privacy:** Never commit credentials, private client data or API keys.
